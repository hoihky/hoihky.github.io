關於

我是一名軟體架構師，職業生涯橫跨資本市場、企業級平台與開源系統程式設計。 如今我尤其專注於遊戲引擎開發與 C# / .NET 生態系——而這些工作建立在多年交付生產級軟體的基礎之上： 在那些系統裡，延遲、可靠性與正確性在每個交易日都至關重要。

資本市場

我曾在頂級投資銀行與自營交易公司工作，建構並維運期權與股票交易的核心系統。 經驗涵蓋訂單路由、定價、風控，以及支撐交易台競爭力的低延遲基礎設施—— 毫秒級回應與結果正確性，缺一不可。

企業級軟體

除金融領域外，我還交付過大規模業務系統，包括文件管理平台、呼叫中心系統， 以及 Office 辦公外掛程式。這些專案需要穩健的工作流程、與現有企業工具的整合， 以及非技術使用者每日可依賴的介面體驗。

目前方向

如今我將系統程式設計背景投入開源工作：C++ 遊戲引擎、.NET 類別庫、嵌入式 OLAP 資料庫， 以及透過建構真實軟體來講授知識的技術電子書——從 Vulkan 渲染與 Roslyn 原始碼產生器， 到跨平台 UI 與生產程式碼庫中的設計模式實踐。

無論在哪個領域，我都傾向於解決效能、工具鏈與開發者體驗交會的問題—— 無論是交易技術棧、企業工作流程，還是遊戲引擎管線。

專案

開源作品涵蓋原生與瀏覽器遊戲引擎、.NET 類庫，以及為技術電子書提供支援的靜態網站產生器。

遊戲引擎與編輯器

Spark

C++23 Vulkan

C++23 遊戲引擎，配備 Vulkan 前向渲染器、實體–元件場景模型、 保留模式 GUI 與開發中的編輯器。SparkDemo 內建 19 種示範模式。

網站 ↗ · 程式碼儲存庫 ↗

NovaEngine

TypeScript Three.js ECS

模組化瀏覽器 3D 遊戲引擎，基於 TypeScript、Three.js 與 ECS 架構—— 遊戲邏輯在元件與系統中，渲染透過 WebGL2/WebGPU 後端抽象。 包含 Nova Collector 示範遊戲，正演進為商業級 Web 工具鏈。

網站 ↗ · 程式碼儲存庫 ↗

Spark Studio

C# Avalonia

基於 Spark 引擎的跨平台 C# Avalonia 遊戲編輯器，支援 2D 與 3D， 整合 SkyUI、LightMediator 與 LightMapper。

程式碼儲存庫 ↗

Spark Templates

C++ CMake

將 Spark 作為類別庫連結的獨立遊戲專案範本——ARPG、平台跳躍等入門起點， 展示 Spark 公開 API 的用法。

.NET 類庫與工具

SkyUI

C# Avalonia

基於 Avalonia 的 .NET 跨平台 UI 類別庫——設計系統、樣式化控制項、 資料表格與圖表模組，採用內容優先的暗色主題。

網站 ↗ · 程式碼儲存庫 ↗

LightMapper

C# Roslyn

基於 Roslyn 原始碼產生器的 .NET 編譯期物件對應器， 對應熱路徑無需反射。

網站 ↗ · 程式碼儲存庫 ↗

LightMediator

C# CQRS

輕量高效的 .NET 程序內中介者，支援 CQRS 風格請求與通知， 以及基於 Microsoft.Extensions.DependencyInjection 的中介軟體管線。

網站 ↗ · 程式碼儲存庫 ↗

RainDB

C# OLAP

.NET 嵌入式欄式分析資料庫——向量化執行，SQL 與規劃中的 LINQ 共享查詢 IR，在 .NET 生態系內實現 DuckDB 風格的目標。

MDWeb

將 Markdown 資料夾轉換為文件網站的靜態網站產生器—— 支援搜尋、語法醒目提示、Mermaid 圖表、監看模式與 PDF 匯出。
